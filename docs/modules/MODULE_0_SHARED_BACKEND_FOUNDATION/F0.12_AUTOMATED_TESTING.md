# F0.12 — Automated Testing Infrastructure

## 1. Task ID and Task Name
- **Task ID**: `F0.12`
- **Task Name**: Automated Testing Infrastructure

## 2. Objective
Establish an automated test runner suite utilizing the Node.js native test runner (`node:test` and `node:assert/strict`) covering unit tests, middleware security tests, request validation tests, database rollback tests, multi-tenant isolation tests, and end-to-end HTTP integration tests.

## 3. Why This Task Is Necessary
Automated testing guarantees that architectural invariants (e.g. server-authoritative tenant isolation, rejection of client overrides, rollback on database transaction failure) are strictly maintained and never regress during subsequent module development.

## 4. Architecture and Implementation Approach
- **Zero Heavy Dependencies**: Utilizes the built-in Node.js test runner (`node:test`) and strict assertions (`node:assert/strict`), avoiding heavy third-party testing runner overhead.
- **Multi-Level Test Pyramid**:
  1. **Unit Tests** (`test/validation.test.js`): Verifies Zod parsing and strict key filtering in memory.
  2. **Security & Mock Tests** (`test/security.test.js`): Tests middleware behavior using isolated mock requests and dependency-injected query functions.
  3. **Database Integrity Tests** (`scripts/check-db.js`): Executes real rollback and connection verification against MySQL.
  4. **Multi-Tenant Repository Tests** (`scripts/test-tenant.js`): Verifies that cross-tenant lookups return `null`.
  5. **HTTP End-to-End Tests** (`test/api.test.js`): Starts an ephemeral HTTP server and runs live `fetch` calls through the full Express middleware pipeline.

- `npm test`: Executes `node --test test/security.test.js test/validation.test.js test/api.test.js`.
