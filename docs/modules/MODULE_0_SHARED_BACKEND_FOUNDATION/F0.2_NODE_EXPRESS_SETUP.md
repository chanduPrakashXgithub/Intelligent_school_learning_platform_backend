# F0.2 — Node.js and Express Application Setup

## 1. Task ID and Task Name
- **Task ID**: `F0.2`
- **Task Name**: Node.js and Express Application Setup

## 2. Objective
Initialize the production-ready HTTP runtime for the School Learning Platform backend using Express 5.3, configure global security headers, CORS origin filtering, request body parsing limits, and implement graceful shutdown mechanics.

## 3. Why This Task Is Necessary
A structured application container is required to manage incoming HTTP connections, route traffic to modular controllers, enforce uniform security policies across all endpoints, and cleanly disconnect from network resources and MySQL connection pools when terminating.

## 4. Architecture and Implementation Approach
- **Modular Separation**: The application configuration (`src/app.js`) is separated from the network listener (`src/server.js`), allowing `app.js` to be imported directly into integration tests without binding to a live network port.
- **Modern ES Modules**: Configured with `"type": "module"` in `package.json` for native ES imports.
- **Graceful Shutdown**: The server traps `SIGTERM` and `SIGINT` signals, halts incoming HTTP traffic, allows active in-flight requests to complete, and cleanly closes the MySQL connection pool before exiting.

## 6. Explanation of Important Functions and Components
- `app`: Central Express instance mounted with global middleware: `requestIdMiddleware`, `helmet()`, `cors(corsOptions)`, `express.json({ limit: "1mb" })`, and `express.urlencoded()`.
- `corsOptions`: Restricts origin requests strictly to the allowlisted domains configured in `env.CORS_ORIGINS`, while permitting non-browser requests (e.g. Postman, CLI test tools).
- `server.listen(env.PORT)`: Binds to the designated port.
- `shutdown(signal)`: Gracefully terminates the process, prevents double-invocation via `isShuttingDown` flag, calls `server.close()`, and invokes `closeDatabasePool()`.

## 7. Execution Flow
```
Process Start ➔ Load env.js ➔ Initialize Express app ➔ Attach Middlewares ➔ Mount /api/v1 ➔ Listen on PORT
Process Signal (SIGINT/SIGTERM) ➔ Stop accepting new HTTP requests ➔ Close MySQL pool ➔ Exit 0
```

## 8. Database Interaction
During graceful shutdown, `server.js` calls `closeDatabasePool()` in [src/core/database/pool.js](file:///E:/School_Learning_platform/backend/src/core/database/pool.js) to drain all active MySQL connections.

## 11. Security Considerations
- `helmet()` automatically applies secure HTTP headers (e.g. `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, strict HSTS).
- Request body size is hard-capped at 1MB to prevent memory exhaustion / Denial of Service attacks.
- CORS strictly rejects unapproved web origins.
